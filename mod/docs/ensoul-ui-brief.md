# Ensoul(有灵)前端设计简报 —— 交接给 Claude Design

**一句话**:这是 Minecraft 模组的**游戏内 GUI**,不是网页——即时模式像素绘制,每帧重画。目标:为 Ensoul(有灵)建立视觉身份,并升级现有同伴面板。副标题:*They were never NPCs.*

---

## 1. 技术栈与硬约束(必读,越界即不可实现)

- Java + Minecraft 26.1.2 原生 GUI:`Screen` 子类 + `GuiGraphics` 即时绘制。**没有** HTML/CSS/SVG/动画库/布局引擎。
- 可用绘制原语:
  - 纯色矩形填充(ARGB,支持半透明)
  - PNG 贴图 blit(可手写 9-slice)
  - MC 位图字体 drawString(**支持中文**;行高 9 逻辑像素;只能整数倍缩放)
  - 裁剪(scissor)、玩家皮肤头像、物品图标(可直接渲染)
- **坐标系 = 逻辑 GUI 像素**,玩家端按 GUI Scale(1–4)整数放大。设计必须落在整数像素网格,最小细节 1 逻辑像素。
- **主面板画布:380 × 232 逻辑像素**(PAD=8,输入行高 18,ctx 水位条高 12,左侧另有头像栏)。就按这个画布设计。
- 资产:像素风 PNG(1:1 像素,禁抗锯齿),图标惯例 8×8 / 16×16;mod 图标 128×128。
- 能做:硬偏移阴影、描边、抖动/点阵纹理、按帧手写的简单动效(需给出关键帧逻辑)。
- 不能做:渐变羽化、圆角、模糊、字体更换(除非整套位图字体资产)。

## 2. 现有设计系统(可继承、可整套推翻)

代码里已有程序化主题系统 **BlockFrame(neobrutalist)**:厚边框 + 硬偏移阴影 + 直角 + 点阵底纹。

**铁律(建议保留)**:填充=可点击(按钮/输入框/tab 才有填充+边框+硬阴影);状态展示(消息、工具调用、计划项)=纯文本+彩色字形,绝不做填充药丸。

**主题 = 15 个颜色令牌**(换一套值即整体换肤):

| 令牌 | 用途 | 现役值(Cottage 暖色) |
|---|---|---|
| ground | 面板底色 | `#CBA87B` |
| dot | 点阵底纹 | `#2A2012` @17%α |
| band | 标题带/tab 带 | `#6E8F66` |
| onBand | 带上文字 | `#F6EFD9` |
| border | 边框+硬阴影 | `#352818` |
| text / textDim | 正文/次要 | `#352818` / `#6E5E48` |
| field | 输入框底 | `#BE9C70` |
| cta / onCta | 主按钮/其上文字 | `#E3A23A` / `#2A2012` |
| reply | 同伴回复 | `#4E7480` |
| ok / run / fail | 工具成功/运行中/失败 | `#577E3C` / `#A8731E` / `#A8533A` |

另有 VANILLA / FORMAT(经典青)/ DIAMOND / COZY 四套预设可参考。**交付新视觉的最小形式 = 这 15 槽的新值**;要加新槽需说明用途。

## 3. 信息架构(现有界面全景)

- **左侧栏**:同伴花名册(皮肤头像、选中高亮、`+` 召唤)
- **主面板三 tab**:Chat / Items / Settings
- **Chat**:消息流(主人/同伴,流式打字)、思考折叠行(可展开的 reasoning)、工具调用组折叠行(带 run/ok/fail 状态)、输入框 + Send + Stop、手动压缩按钮、**ctx 水位条**(如 `23.4k/100k`,绿<60% 黄<85% 红)
- **Items**:同伴背包网格(秒级刷新)
- **Settings**:供应商/模型/站点下拉、API key、Reasoning 档位循环按钮、**每同伴「模式:生存/创造」+「OP:开/关」**、Save;子页 **Usage**(会话统计 + `cache NN%` + 余额 + 导出)
- **召唤对话框**:名字输入 + 取消/删除

## 4. 数据接口(UI 拿得到的一切——别设计拿不到的数据)

- 花名册:`{uuid, name, gameType(生存/创造), opEnabled}`(服务端权威)
- 聊天流:文本增量、思考增量(独立通道)、工具调用组 `{name, args, result, 状态}`、每请求 usage
- 用量:`{requests, promptTokens, completionTokens, cacheHitRate ∈ [0,1] 或 -1=供应商未上报}`(未知≠0%,未知时应隐藏)
- 水位:当前 prompt tokens / 模型窗口(现 100k)
- 配置:provider / baseUrl / model / apiKey / reasoningEffort / systemPrompt
- 指令:发消息、Stop 打断、召唤/解散、切模式、切 OP、请求压缩、导出上下文
- **(在建)外脑接管态**:同伴可能被外部 agent(MCP)接管——需要一个"被接管中"的视觉状态
