# 空闲自主层 L3(Idle Autonomy)— 设计正典 v1

**没人管它时,身体自己过日子。**

## 0. 架构定位
脊髓 L3。不是反射(反射毫秒级打断),不是大脑(零 LLM 调用)。夹在两者之间:全程状态机 + 复用现有肌肉/寻路/交战引擎/注意力,**零 token**。生物学近似基底节习惯回路,但正典归脊髓 L3,不加新名词。

铁律:凡实时必肌肉;informs-never-consults(干了什么全部追加落账,大脑醒来读"梦游日记")。

## 2. 主人裁定(2026-07-18 锁定)
- **火把权 = 仅系留半径内**:只在锚点半径内的黑暗处放火把,不去荒野改造地貌。
- **杀生权 = 完全禁止**:自主状态绝不主动杀生(含野生);缺粮只追加上下文饥饿提示,由大脑/主人决定。→ Wave C 猎杀逻辑取消。
- **存物权 = 一切归背包,不碰任何容器**:永不开箱(含自己放的);背包满则停止拾取/采集。→ 归巢整备去掉存物状态机。
- **系留半径 = 在线 24 / 离线 8**(设置面板可调,能力矩阵第三旋钮)。

## 3. 仲裁与红线(本层宪法)
- 优先级最底:**反射 > 主人任务 > 大脑回合在飞 > 空闲自主**。任何上层活动出现,当 tick 让位,未完成闲事直接扔(无清理债)。仲裁复用 `Reflexes.ownsBody(uuid)` + 任务活跃 + 大脑回合在飞三查。
- 动作白名单:移动/注视/拾取/采可再生/吃/穿戴/放自己的火把与脚手架(仅半径内)。
- 黑名单:拆任何非自己放置的方块(shouldAvoidBreaking 全时生效)、开任何容器、攻击任何生物(杀生禁止)、越出系留半径。
- 节奏:强制行为间冷却,大部分时间"站着看看+慢慢晃",偶尔干一件事。**灵动≠忙碌**。
- 每 NPC 开关:设置面板"自主:开/关"+ 系留半径。创造态适用(飞着晃留给创造波)。

## 4. 实施波次
- **Wave A(最小可爱版)**:调度器骨架 + 系留漫步 + 拾取 + 梦游日记。
- Wave B:认知空白探索 + 好奇接近。
- Wave C:夜间避险 + 归巢整备(无杀生、无存物)。
- Wave D:自主战斗收口(交战 AVOID 接进漫步寻路)。
